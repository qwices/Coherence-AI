## 🌍 1. About the Project

**Coherence AI** is an AI-powered system designed to detect antenna deformation and help correct microwave beam direction in Space-Based Solar Power (SBSP) systems.

Space-based solar power is a technology that collects solar energy in space and transmits it to Earth using microwaves.

However, large orbital antennas can experience temperature changes, structural deformation, and alignment errors.

These problems can cause microwave beams to deviate from their intended direction, resulting in energy losses.

**Our goal is to develop an intelligent system that helps detect these changes and calculate the necessary corrections.**

## 🎯 2. Problem Statement

Space-based solar power systems face several technical challenges:

- Antennas heat up when exposed to sunlight.
- Temperature changes can cause structural deformation.
- Antenna deformation can affect beam alignment.
- Incorrect alignment can reduce energy transmission efficiency.

Even small structural changes can affect the precision of a large antenna system.

## 💡 3. Our Solution

Coherence AI combines sensor data analysis and artificial intelligence to monitor antenna conditions.

The system is designed to:

- Monitor temperature changes.
- Detect structural deformation.
- Analyze antenna condition.
- Predict possible beam deviation.
- Calculate the required correction.
- Help maintain accurate beam alignment.

Our project focuses on one important part of future space-based solar power systems: intelligent antenna monitoring and correction.

## ⚙️ 4. How Does It Work?

The system follows five main steps:

1. **Data Collection** — Sensors collect temperature and deformation data.
2. **Data Processing** — The collected information is transferred to the software.
3. **AI Analysis** — The AI model analyzes the data and identifies possible problems.
4. **Prediction** — The system estimates possible beam deviation.
5. **Correction** — The software calculates a correction to restore the intended beam direction.

## 🤖 5. Role of Artificial Intelligence

Artificial Intelligence is an important part of Coherence AI.

The AI component is intended to analyze sensor measurements and help identify changes in antenna conditions.

Its main functions include:

- Sensor data analysis.
- Deformation detection.
- Beam deviation prediction.
- Correction calculation.
- System optimization.

For example, if the antenna temperature increases, the system can analyze the measurements and estimate whether this change may affect antenna alignment.

The AI model can then help determine the necessary correction.

**AI is not included just for demonstration. It has a specific technical purpose in our project.**

## 🖥️ 6. Minimum Viable Product (MVP)

Our MVP is an educational prototype that demonstrates the main concept of Coherence AI.

It consists of two possible components.

### A. Digital Simulation

The digital simulation is the main part of our MVP.

Users will be able to:

- View a model of a space-based solar power station.
- Change the simulated temperature.
- Change the solar angle.
- Simulate antenna deformation.
- Observe microwave beam deviation.
- Activate the AI correction function.
- Compare energy losses before and after correction.

The simulation will also include graphs to visualize the difference between the two scenarios.

### B. Physical Prototype (Optional)

If resources are available, we plan to create a small physical model.

Possible components:

- ESP32 or Arduino.
- Temperature sensor.
- Bending sensor.
- LEDs.
- Flexible plastic plate.
- Breadboard and wires.

The physical prototype will demonstrate how sensor measurements can be collected and processed.

**Important:** The prototype does not transmit real microwave energy. It is a safe educational demonstration of the system's concept.
